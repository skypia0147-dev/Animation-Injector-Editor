# Animation Injector Editor · 1.0.0

Animation Injector（SKSE）のアクション（通常・ペア）をカードのグラフで作成し、ゲームが読む XML または MOD フォルダとして出力する Windows プログラムです。

## 必要なもの

- Windows 10/11 x64、Microsoft Edge WebView2 ランタイム（Windows 11 には標準で含まれます）
- ゲームで使うには **Animation Injector 0.12.296 以降**（[GitHub](https://github.com/skypia0147-dev/Animation-Injector)）とその必須 MOD
- 同梱の `AnimationInjectorXmlCheck.exe` を `AnimationInjectorEditor.exe` と同じフォルダに置いてください。保存時にゲームのランタイムと同じ検査を行い、ゲームが丸ごと無視する XML は書き込みません。このファイルがない場合は検査なしで保存し、警告を表示します。

Node.js・Rust・Python などの開発ツールは不要です。

## 最初のアクション

1. **新規プロジェクト** を作成するか、XML・テンプレート（`.aitemplate`）を開きます。ウィンドウにドロップしても開けます。`examples` フォルダに例があります。
2. ツールバーの **＋ HKX 再生** でカードを作り、カードの **ファイル** で HKX を選びます。HKX は `meshes\actors\<キャラクター・クリーチャーのフォルダ>` の下に置き、その下のパスには英数字と一般的な記号だけを使ってください（それ以外の文字を含むパスのファイルはゲームが見つけられません）。
3. カードを右クリックし、**開始キー入力を追加** または **開始イベントを追加** でアクションの開始方法を決めます。
4. カードの **+ 機能** から無敵・よろめき無効・回転・リソース消費・カメラ復帰などを追加します。アクション全体で有効な機能と特定の瞬間に実行する機能は一つのリストで扱います。
5. 次の HKX へつなぐには、カードを右クリックして **遷移キー入力を追加** または **遷移イベントを追加** を選び、出力ピンを次のカードへドラッグするか、ピン行の **▾** リストから選びます。
6. **F7** で検査し、**Ctrl+S** で保存します。エラー一覧の項目をクリックすると該当カードへ移動します。

## グラフの操作

- 入力・イベント・条件・QTE・遷移はすべて一つのキャンバスにあります。カードをダブルクリックすると、そのアクションの流れだけを表示します。
- **整列 ▾**：全体を整列、選んだアクションだけ整列、要約表示／展開表示。
- 空いている場所をドラッグして複数のカードを選択します（触れるだけで選択）。Shift で追加、Ctrl で切り替え、Space＋ドラッグで画面移動です。
- カードを選ぶとそのリンクを強調します。色のないリンクは出ていくものが水色、入ってくるものがピンク色になり、役割・結果の色があるリンクはその色のまま明るく太く表示されます。
- HKX カードの設定と機能はカードで編集します。右の詳細パネルには、そのアクションの問題・接続・HKX ファイルが表示されます。
- **条件分岐** は成功・失敗の経路を、**QTE** は結果（成功・失敗・パーフェクト）ごとに継続・イベント・遷移を決めます。
- **イベント登録** カードには、プロジェクトで使うイベント名とその機能をまとめます。

## 保存と出力

- **保存（Ctrl+S）** はゲームが読む XML をそのまま書き込み、ファイル末尾のコメントに編集情報（カード配置・設定共有など）を入れます。ゲームはこのコメントを読みません。この XML を開き直すと、そのまま編集を続けられます。
- 編集情報にはこのコンピューターのパス（HKX 原本・検索フォルダ・プレビュー用アセット）を入れません。同じコンピューターで開き直すとパスが復元され、別のコンピューターでは XML と同じ MOD フォルダ内の HKX とサウンドファイル（`<MOD フォルダ>\sound\…`）を自動で探し直します。XML を開くと、その MOD フォルダの `sound` 以下のサウンドファイル（.wav・.xwm）がすべて ブラウザパネルの「サウンド」に登録され、▶ ですぐに試聴できます（.wav のみ）。MOD の esp が HKX 注釈（SoundPlay）で再生するサウンドのように XML が名前を挙げないファイルも含まれ、登録されたサウンドは MOD フォルダへのエクスポート時に一緒にコピーされます。使わないサウンドは ✕ で登録を外し、「+」で追加できます。サウンド再生機能は出所を「ファイル」または「登録サウンド」から選び、ファイルは読み込んだサウンドの一覧から選びます。
- エラーがあっても保存できます。一度保存したファイルなら、ゲームが読む本文は最後の正常な内容のまま、編集情報だけを更新します。初めて保存するファイルなら、ゲームが読む本文を空にして編集情報だけを保存し、エラーを直して保存し直すまでゲームはそのファイルを読み飛ばします。
- ファイルがこのエディタの外（別のエディタウィンドウ、テキストエディタ、同期ツール）で変更されていた場合は、上書きする前に確認します。
- **エクスポート → XML（Ctrl+E）** は、エラーがないときに XML を別に保存します。
- **エクスポート → MOD フォルダ（Ctrl+Shift+E）** は `<MOD 名>\SKSE\Plugins\AnimationInjector\<MOD 名>\<MOD 名>.xml` と使用する HKX・サウンドファイルを出力します。検索フォルダを指定してアセットを検査し、他の MOD やゲームが提供するファイルは外部提供として扱います。同じ名前のフォルダがある場合は上書きしません。
- 保存する XML は形式 6（`version="6"`、Animation Injector 0.12.291 以降）です。キャンバスの開始カード・条件カード・HKX カードがファイルの `<Start>`・条件カード（`<Check>`・`<Row>`・`<True>`・`<False>`）・`<Action>` と一対一で対応し、二か所以上から向かう条件カードはルートの `<Condition>` として一度だけ書かれます。形式 4・5 の XML は形式 6 に変換して開き、保存すると形式 6 になります。
- キー入力はキー・パッドを直接指定するか、ゲーム操作（ジャンプ、ダッシュ、隠密、アクティベート …）から選べます（Animation Injector 0.12.292 以降）。ゲーム操作を選ぶと、プレイヤーがその操作に割り当てたキーボード・マウス・ゲームパッドのキーすべてで動作し、その入力で動作が始まると本来のゲーム動作（実際のジャンプ）は起きません。開始・遷移・QTE・運搬の下ろす操作で使えます。
- HKX カードの「打撃」（Animation Injector 0.12.293 以降）は、エンジンがその武器で殴ったときのダメージ（スキル・パーク・対象の防具を含む）を割合で、または固定ダメージを、決めた対象に与えます。対象はペアの相手・戦闘相手・照準の対象、または範囲（半径・角度・足元基準の高さ・減衰）で、HitFrame の判定円錐は使いません。区間を指定するとその間に入った対象に一度ずつ当てます。ラグドール中や壁の向こうの対象には当たりません。当たった後の反応（よろめき・押し飛ばし）を選べ、本物の打撃のように武器のエンチャント・毒・パーク効果・打撃音と血・被弾イベントが一緒に起きます（項目ごとにオフにできます、0.12.294 以降）。
- 条件カードの検査項目に直前の動作（このプロジェクトの動作のうち最後に終えたもの）・落下中・地面の傾き・能力値の比較・ゲーム内時刻・天気があり、HKX カードの機能にサウンド再生（Data 以下のファイルまたは登録サウンド）・グローバル値の設定（動作終了時に戻すこともできます）・MOD イベント送信があります（0.12.296 以降）。サウンドファイルは欄の横の「参照」で選ぶと（MOD または Data の sound フォルダー以下）パスが入り、MOD フォルダーへのエクスポート時に同じパスへコピーされます。
- 以前の形式（version 1〜3）の XML と、コンボを含むテンプレートは開けません。エディタで作り直して保存してください。

## ビューア

**ウィンドウ → ビューポート** で選んだ HKX を再生します。配布版には人間とクリーチャーのプレビュー用スケルトンとスキンが入っており、対応する HKX はすぐに再生できます。ソースから自分でビルドした場合は含まれないため、ビューポートの **プレビュー資産** でスケルトン HKX（例: `meshes\actors\character\character assets\skeleton.hkx`）を指定してください。指定したファイルはこのコンピューターで記憶され、HKX と同じ MOD の `actors` フォルダーにスケルトンがあれば自動で見つけます。GLB スキンがない場合は骨格だけを表示します。

- 中ボタンドラッグ：回転 · Shift＋中ボタンドラッグ：移動 · ホイール：ズーム · Ctrl＋ホイール：視野角

ビューアはゲームの OAR 選択・IK・衝突・物理を再現しません。最終確認はゲーム内で行ってください。

## ショートカット

| キー | 操作 |
|---|---|
| Ctrl+N / O / S | 新規プロジェクト / 開く / 保存 |
| Ctrl+Shift+S | 名前を付けて保存 |
| Ctrl+E / Ctrl+Shift+E | XML をエクスポート / MOD フォルダをエクスポート |
| F7 | コンパイル（検査） |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Ctrl+A · Delete | すべて選択 · 削除 |
| Home | 全体表示 |
| Ctrl+` | XML プレビュー |

## 言語と自動保存

- **言語** メニューで English・한국어・日本語・中文 をすぐに切り替えられます。ユーザーが入力した名前は変わりません。
- 編集中の内容は自動で保存されます。異常終了した後は、開始画面の **自動保存から復元** で戻せます。
