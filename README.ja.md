# Animation Injector Editor · 1.0.0

[Animation Injector](https://github.com/skypia0147-dev/Animation-Injector) 用のアクション MOD を作る Windows プログラムです。HKX をカードとして置いてつなぎ、アクション（一人で行うもの・ペア）を作って、ゲームが読む XML または MOD フォルダとして出力します。

## 必要なもの

- Windows 10/11 x64、Microsoft Edge WebView2 ランタイム（Windows 11 には標準で入っています）
- ゲームで使うには **Animation Injector 1.0.0 以降** とその必須 MOD
- 同梱の `AnimationInjectorXmlCheck.exe` を `AnimationInjectorEditor.exe` と同じフォルダに置いてください。保存するとき、ゲームがその XML を読めるかを検査します。ない場合は検査せずに保存し、警告を表示します。

## はじめての作成

1. **新規プロジェクト** を作るか、保存済みの XML・テンプレート（`.aitemplate`）を開きます。ウィンドウにドラッグ＆ドロップしても開けます。
2. ツールバーの **＋ HKX 再生** でカードを作り、カードの **ファイル** で HKX を選びます。HKX は `meshes\actors\<キャラクター・クリーチャーのフォルダ>` の下に置き、パスには英数字と一般的な記号だけを使ってください（英語以外の文字を含むパスのファイルはゲームが見つけられません）。Action ID は HKX のファイル名から決まります。
3. カードを右クリックし、**開始キー入力を追加** または **開始イベントを追加** でアクションの開始方法を決めます。
4. カードの **+ 機能** から、無敵・よろめき耐性・回転・リソース消費・打撃などの機能を加えます。アクションの間ずっと有効な機能と、特定の瞬間に実行する機能を一つのリストで扱います。
5. 次のアクションにつなぐには、カードを右クリックして **遷移キー入力を追加** または **遷移イベントを追加** を選び、出力ピンを次のカードへドラッグするか **▾** リストから選びます。
6. **F7** で検査し、**Ctrl+S** で保存します。エラー一覧の項目をクリックするとそのカードへ移動します。

## グラフの操作

- 入力・イベント・条件・QTE・遷移はすべて一つのキャンバスにあります。カードをダブルクリックすると、そのアクションの流れだけを表示します。
- **整列 ▾**：全体整列、選んだアクションだけ整列、要約表示／展開表示。
- 空いている場所をドラッグして複数のカードを選びます。Shift で追加、Ctrl で切り替え、Space＋ドラッグで画面移動です。
- カードを選ぶと、そのカードにつながる線が強調されます。
- イベント遷移カードは複数の HKX で共有できます。HKX の出力ピンを既存の遷移カードに置くと、同じ遷移を使います。
- 3 つ以上の HKX が共有する遷移は、線の代わりに各 HKX カードの **→ 遷移 ①** 表示で示されます。その HKX か遷移カードを選ぶと線が表示されます。表示を押すとその線が選ばれ、Delete で接続を切ります。
- **条件カード** は状況（武器・移動方向・空中・直前のアクション・受けた攻撃・天気など）に応じて進むアクションを選び、**QTE** は結果（成功・失敗・パーフェクト）ごとに次のアクションを決めます。
- **イベント登録** カードには、プロジェクトで使うイベント名とそのイベントが行うことをまとめます。
- キー入力は、キー・パッドボタンを直接指定するか、ゲーム操作（ジャンプ、ダッシュ、隠密 …）から選べます。ゲーム操作はプレイヤーのキー設定に従います。

## 保存と出力

- **保存（Ctrl+S）** はゲームが読む XML として保存します。カードの配置などの編集情報も同じファイルに入るので、開き直してそのまま編集を続けられます。
- 別のコンピューターで開いても、XML と同じ MOD フォルダ内の HKX とサウンドファイルを自動で見つけ直します。
- エラーがあっても保存できますが、エラーを直して保存し直すまで、ゲームはそのファイルを読みません（以前に保存したことのあるファイルなら、最後の正常な内容を読みます）。
- ファイルがこのエディタの外で変更されていた場合は、上書きする前に確認します。
- **エクスポート → XML（Ctrl+E）** は、エラーがないときに XML を別に保存します。
- **エクスポート → MOD フォルダ（Ctrl+Shift+E）** は、MOD マネージャーでそのままインストールできるフォルダを作ります。XML と使用する HKX・サウンドファイルが入り、他の MOD やゲームが提供するファイルは区別して表示します。同じ名前のフォルダがあれば上書きしません。
- ブラウザーパネルの **サウンド** には MOD フォルダのサウンドファイルが集まります。▶ で試聴でき（.wav）、MOD フォルダを出力するときに一緒にコピーされます。

## ビューア

**ウィンドウ → ビューポート** で、選んだ HKX を再生します。人・クリーチャーのプレビュー用スケルトンとスキンが入っているので、すぐに再生できます。別のスケルトンを使うには、ビューポートの **プレビューアセット** で指定してください。

- 中ボタンドラッグ：回転 · Shift＋中ボタンドラッグ：移動 · ホイール：ズーム · Ctrl＋ホイール：視野角

ビューアはゲームの衝突・物理などを再現しません。最終確認はゲームで行ってください。

## ショートカット

| キー | 動作 |
|---|---|
| Ctrl+N / O / S | 新規プロジェクト / 開く / 保存 |
| Ctrl+Shift+S | 名前を付けて保存 |
| Ctrl+E / Ctrl+Shift+E | XML をエクスポート / MOD フォルダをエクスポート |
| F7 | 検査 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+A · Delete | すべて選択 · 削除 |
| Home | 全体表示 |
| Ctrl+` | XML プレビュー |

## 言語と自動保存

- **言語** メニューで English・한국어・日本語・中文 を切り替えます。
- 編集中の内容は自動で保存されます。異常終了の後は、スタート画面の **自動保存から復元** で元に戻せます。
