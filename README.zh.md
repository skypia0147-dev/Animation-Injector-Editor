# Animation Injector Editor · 1.0.0

用于以卡片图形制作 Animation Injector（SKSE）动作（普通与配对），并导出为游戏读取的 XML 或模组文件夹的 Windows 程序。

## 运行需求

- Windows 10/11 x64，Microsoft Edge WebView2 运行时（Windows 11 已自带）
- 在游戏中使用需要 **Animation Injector 0.12.292 或更高版本**（[GitHub](https://github.com/skypia0147-dev/Animation-Injector)）及其前置模组
- 请将随附的 `AnimationInjectorXmlCheck.exe` 与 `AnimationInjectorEditor.exe` 放在同一文件夹。保存时会执行与游戏运行时相同的检查，不会写出会被游戏整体忽略的 XML。缺少该文件时会在不检查的情况下保存并给出警告。

不需要 Node.js、Rust、Python 等开发工具。

## 第一个动作

1. 创建 **新项目**，或打开 XML、模板（`.aitemplate`）；拖放到窗口上也可以打开。`examples` 文件夹中有示例。
2. 用工具栏的 **＋ 播放 HKX** 创建卡片，并在卡片的 **文件** 中选择 HKX。HKX 必须位于 `meshes\actors\<角色或生物文件夹>` 之下，该文件夹以下的路径只能使用英文字母、数字和常用符号（路径含其他字符时游戏找不到文件）。
3. 右键单击卡片，选择 **添加开始按键输入** 或 **添加开始事件**，决定动作如何开始。
4. 通过卡片上的 **+ 功能** 添加无敌、免疫硬直、旋转、资源消耗、镜头恢复等功能。在整个动作期间生效的功能与在特定时刻执行的功能在同一列表中管理。
5. 要接到下一个 HKX，右键单击卡片选择 **添加转换按键输入** 或 **添加转换事件**，然后把输出引脚拖到下一张卡片，或从引脚行的 **▾** 列表中选择。
6. 按 **F7** 检查，按 **Ctrl+S** 保存。点击错误列表中的项目会跳转到对应卡片。

## 操作图形

- 输入、事件、条件、QTE 和转换都在同一画布上。双击卡片只显示该动作的流程。
- **排列 ▾**：全部排列、只排列所选动作、摘要视图／展开视图。
- 在空白处拖动可选择多张卡片（碰到即选中）。Shift 为添加，Ctrl 为切换，Space＋拖动为移动画面。
- 选中卡片时会突出显示它的连线。没有颜色的连线中，出去的变为浅蓝色，进来的变为粉色；已有角色或结果颜色的连线保持原色，并变得更亮更粗。
- HKX 卡片的设置与功能在卡片上编辑；右侧细节面板显示该动作的问题、连接和 HKX 文件。
- **条件分支** 设置通过与失败的路径；**QTE** 为每个结果（成功、失败、完美）设置继续、事件或转换。
- **事件注册** 卡片汇总项目中使用的事件名称及其功能。

## 保存与导出

- **保存（Ctrl+S）** 按游戏读取的 XML 原样写入，并在文件末尾的注释中保存编辑信息（卡片布局、共享设置等）。游戏不会读取该注释；重新打开该 XML 即可继续编辑。
- 编辑信息中不包含本机路径（HKX 原文件、搜索文件夹、预览资源）。在同一台电脑上重新打开时会恢复这些路径；在其他电脑上会自动重新查找与 XML 位于同一模组文件夹内的 HKX。
- 即使有错误也可以保存。已经保存过的文件会保持游戏读取的正文为上一次的正常内容，只更新编辑信息；首次保存的文件会将游戏读取的正文留空，只保存编辑信息，在修正错误并重新保存之前，游戏会跳过该文件。
- 如果文件在此编辑器之外（其他编辑器窗口、文本编辑器、同步工具）被更改，覆盖前会先询问。
- **导出 → XML（Ctrl+E）** 在没有错误时另存一个 XML。
- **导出 → 模组文件夹（Ctrl+Shift+E）** 输出 `<模组名>\SKSE\Plugins\AnimationInjector\<模组名>\<模组名>.xml` 以及使用的 HKX。指定搜索文件夹以检查资源，由其他模组提供的 HKX 标记为外部提供。已存在同名文件夹时不会覆盖。
- 保存的 XML 为格式 6（`version="6"`，需要 Animation Injector 0.12.291 或更高版本）：画布上的启动卡片、条件卡片和 HKX 卡片与文件中的 `<Start>`、条件卡片（`<Check>`、`<Row>`、`<True>`、`<False>`）和 `<Action>` 一一对应，被两处以上指向的条件卡片在根级以 `<Condition>` 写一次。格式 4、5 的 XML 会转换为格式 6 打开，保存后为格式 6。
- 按键输入可以直接指定按键和手柄按钮，也可以选择游戏操作（跳跃、冲刺、潜行、激活……；需要 Animation Injector 0.12.292 或更高版本）。选择游戏操作后，玩家绑定到该操作的键盘、鼠标和手柄按键都会生效；该输入启动动作时，游戏原本的动作（实际跳跃）不会发生。可用于启动、转换、QTE 和搬运放下。
- 无法打开旧格式（version 1～3）的 XML 和含连招的模板。请在编辑器中重新制作并保存。

## 查看器

**窗口 → 视口** 播放所选的 HKX。发布版内置人类和生物的预览骨架与蒙皮，受支持的 HKX 可直接播放。如果是从源码自行构建，则不包含这些文件，请在视口的 **预览资源** 中指定骨架 HKX（例如 `meshes\actors\character\character assets\skeleton.hkx`）。指定的文件会在本机记住；如果 HKX 所在模组的 `actors` 文件夹中有骨架，会自动找到。没有 GLB 蒙皮时只显示骨骼。

- 中键拖动：旋转 · Shift＋中键拖动：平移 · 滚轮：缩放 · Ctrl＋滚轮：视野角

查看器不会模拟游戏中的 OAR 选择、IK、碰撞或物理。最终效果请在游戏中确认。

## 快捷键

| 按键 | 操作 |
|---|---|
| Ctrl+N / O / S | 新项目 / 打开 / 保存 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+E / Ctrl+Shift+E | 导出 XML / 导出模组文件夹 |
| F7 | 编译（检查） |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+A · Delete | 全选 · 删除 |
| Home | 显示全部 |
| Ctrl+` | XML 预览 |

## 语言与自动保存

- 可在 **语言** 菜单中即时切换 English、한국어、日本語、中文。用户输入的名称不会改变。
- 编辑中的内容会自动保存。异常退出后，可在开始界面用 **恢复自动保存** 找回。
