# Animation Injector Editor · 1.0.0

用于制作 [Animation Injector](https://github.com/skypia0147-dev/Animation-Injector) 动作模组的 Windows 程序。把 HKX 作为卡片放置并连接，制作动作（单人动作与配对动作），然后导出为游戏读取的 XML 或模组文件夹。

## 系统要求

- Windows 10/11 x64，Microsoft Edge WebView2 运行时（Windows 11 已自带）
- 在游戏中使用需要 **Animation Injector 1.0.0 或更高版本** 及其前置模组
- 请把附带的 `AnimationInjectorXmlCheck.exe` 与 `AnimationInjectorEditor.exe` 放在同一文件夹。保存时它会检查游戏能否读取该 XML。缺少该文件时会不经检查直接保存并显示警告。

## 第一次制作

1. 创建 **新建项目**，或打开已保存的 XML、模板（`.aitemplate`）。也可以把文件拖放到窗口中打开。
2. 用工具栏的 **＋ 播放 HKX** 创建卡片，在卡片的 **文件** 中选择 HKX。HKX 应放在 `meshes\actors\<角色或生物文件夹>` 下，路径中只使用英文字母、数字和常用符号（路径含非英文字符时游戏找不到文件）。Action ID 取自 HKX 的文件名。
3. 右键点击卡片，选择 **添加开始按键输入** 或 **添加开始事件**，决定动作如何开始。
4. 在卡片的 **+ 功能** 中添加无敌、硬直抗性、转向、资源消耗、打击等功能。整个动作期间保持开启的功能和在特定时刻执行的功能在同一列表中处理。
5. 要连接到下一个动作，右键点击卡片选择 **添加转换按键输入** 或 **添加转换事件**，然后把输出引脚拖到下一张卡片，或在 **▾** 列表中选择。
6. 按 **F7** 检查，按 **Ctrl+S** 保存。点击错误列表中的项目会跳转到对应卡片。

## 操作图表

- 输入、事件、条件、QTE 和转换都在同一画布上。双击卡片只显示该动作的流程。
- **排列 ▾**：全部排列、只排列选中的动作、摘要视图／展开视图。
- 在空白处拖动可选择多张卡片。Shift 添加，Ctrl 切换，Space＋拖动平移画面。
- 选中卡片时，与它相连的线会高亮显示。
- 多个 HKX 可以共用一张事件转换卡：把 HKX 的输出引脚拖到已有的转换卡上即可使用同一转换。
- 三个及以上 HKX 共用的转换不画连线，而是在各 HKX 卡片上显示 **→ 转换 ①** 标记。选中该 HKX 或转换卡时显示连线；点击标记会选中那条连线，按 Delete 断开。
- **条件卡** 根据情况（武器、移动方向、是否在空中、上一个动作、受到的攻击、天气等）选择要进入的动作；**QTE** 为每种结果（成功、失败、完美）设定下一个动作。
- **事件注册** 卡片汇集项目使用的事件名称以及每个事件要做的事。
- 按键输入可以直接指定按键和手柄按钮，也可以选择游戏操作（跳跃、冲刺、潜行……）。游戏操作会跟随玩家的按键设置。

## 保存与导出

- **保存（Ctrl+S）** 保存为游戏读取的 XML。卡片位置等编辑信息也写在同一文件中，重新打开即可继续编辑。
- 在其他电脑上打开时，会自动重新找到 XML 所在模组文件夹中的 HKX 和声音文件。
- 有错误时也可以保存，但在修正错误并重新保存之前，游戏不会读取该文件（以前保存过的文件，游戏读取最后一次正常的内容）。
- 如果文件在本编辑器之外被修改过，覆盖前会先询问。
- **导出 → XML（Ctrl+E）** 在没有错误时另存一个 XML。
- **导出 → 模组文件夹（Ctrl+Shift+E）** 生成可直接用模组管理器安装的文件夹，其中包含 XML 以及用到的 HKX 和声音文件；由其他模组或游戏提供的文件会单独标出。已存在同名文件夹时不会覆盖。
- 浏览器面板的 **声音** 汇集模组文件夹中的声音文件。可以用 ▶ 试听（.wav），导出模组文件夹时会一并复制。

## 查看器

**窗口 → 视口** 播放选中的 HKX。内置人物和生物的预览骨架与蒙皮，可以直接播放。要使用其他骨架，请在视口的 **预览资产** 中指定。

- 中键拖动：旋转 · Shift＋中键拖动：平移 · 滚轮：缩放 · Ctrl＋滚轮：视野角

查看器不会重现游戏的碰撞、物理等效果。最终效果请在游戏中确认。

## 快捷键

| 按键 | 操作 |
|---|---|
| Ctrl+N / O / S | 新建项目 / 打开 / 保存 |
| Ctrl+Shift+S | 另存为 |
| Ctrl+E / Ctrl+Shift+E | 导出 XML / 导出模组文件夹 |
| F7 | 检查 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Ctrl+A · Delete | 全选 · 删除 |
| Home | 显示全部 |
| Ctrl+` | XML 预览 |

## 语言与自动保存

- 在 **语言** 菜单中切换 English、한국어、日本語、中文。
- 编辑内容会自动保存。异常退出后，可在开始画面用 **恢复自动保存** 恢复。
