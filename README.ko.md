# Animation Injector Editor · 1.0.0

Animation Injector(SKSE)의 동작(일반·페어)을 카드 그래프로 만들고, 게임이 읽는 XML이나 모드 폴더로 내보내는 Windows 프로그램입니다.

## 필요 사항

- Windows 10/11 x64, Microsoft Edge WebView2 런타임(Windows 11에는 기본 포함)
- 게임에서 쓰려면 **Animation Injector 0.12.277 이상**([GitHub](https://github.com/skypia0147-dev/Animation-Injector))과 그 필수 모드
- `AnimationInjectorXmlCheck.exe`를 `AnimationInjectorEditor.exe`와 같은 폴더에 둡니다(동봉). 저장할 때 게임의 런타임과 같은 검사를 해서, 게임이 통째로 무시할 XML은 쓰지 않습니다. 이 파일이 없으면 검사 없이 저장하고 경고를 보여 줍니다.

Node.js·Rust·Python 같은 개발 도구는 필요 없습니다.

## 처음 만들기

1. **새 프로젝트**를 만들거나 XML·템플릿(`.aitemplate`)을 엽니다. 창에 끌어다 놓아도 열립니다. `examples` 폴더에 예제가 있습니다.
2. 툴바의 **＋ HKX 재생**으로 카드를 만들고, 카드의 **파일**에서 HKX를 고릅니다. HKX는 `meshes\actors\<캐릭터·크리쳐 폴더>` 아래에 있어야 하며, 그 아래 경로는 영문·숫자·일반 기호만 씁니다(게임이 한글 경로의 파일을 찾지 못합니다).
3. 카드를 오른쪽 클릭해 **시작 키 입력 추가** 또는 **시작 이벤트 추가**로 동작을 시작하는 방법을 정합니다.
4. 카드의 **+ 기능**에서 무적·경직 방지·회전·자원 소모·카메라 복구 같은 기능을 더합니다. 동작 내내 켜는 기능과 특정 순간에 실행하는 기능을 한 목록에서 다룹니다.
5. 다음 HKX로 이으려면 카드를 오른쪽 클릭해 **전환 키 입력 추가**나 **전환 이벤트 추가**를 고른 뒤, 출력 핀을 다음 카드로 끌거나 핀 행의 **▾** 목록에서 고릅니다.
6. **F7**로 검사하고 **Ctrl+S**로 저장합니다. 오류 목록의 항목을 누르면 해당 카드로 이동합니다.

## 그래프 다루기

- 입력·이벤트·조건·QTE·전환이 모두 한 캔버스에 있습니다. 카드를 더블클릭하면 그 동작의 흐름만 보여 줍니다.
- **정렬 ▾**: 전체 정렬, 고른 동작만 정렬, 요약 보기/펼친 보기.
- 빈 곳을 끌어 여러 카드를 고릅니다(걸치기만 해도 선택). Shift는 더하기, Ctrl은 넣고 빼기, Space+끌기는 화면 이동입니다.
- 카드를 고르면 그 카드의 연결선을 강조합니다. 색이 없는 선은 나가는 선이 하늘색, 들어오는 선이 분홍색이 되고, 역할·결과 색이 있는 선은 그 색 그대로 밝고 굵게 표시합니다.
- HKX 카드의 설정과 기능은 카드에서 편집합니다. 오른쪽 디테일 패널에는 그 동작의 문제·연결·HKX 파일이 나옵니다.
- **조건 분기**는 통과·실패 경로를, **QTE**는 결과(성공·실패·완벽)마다 계속·이벤트·전환을 정합니다.
- **이벤트 등록** 카드에는 프로젝트에서 쓰는 이벤트 이름과 그 기능을 모아 둡니다.

## 저장과 내보내기

- **저장(Ctrl+S)** 은 게임이 읽는 XML 그대로 저장하고, 파일 끝 주석에 편집 정보(카드 배치·설정 공유 등)를 함께 넣습니다. 게임은 이 주석을 읽지 않으며, 이 XML을 다시 열면 그대로 이어서 편집할 수 있습니다.
- 편집 정보에는 이 컴퓨터의 경로(HKX 원본·검색 폴더·프리뷰 자산)를 넣지 않습니다. 같은 컴퓨터에서 다시 열면 경로가 복원되고, 다른 컴퓨터에서는 XML과 같은 모드 폴더 안의 HKX를 자동으로 다시 찾습니다.
- 오류가 있어도 저장할 수 있습니다. 이미 저장한 파일이면 게임이 읽는 본문은 마지막 정상 내용으로 두고 편집 정보만 갱신합니다. 처음 저장하는 파일이면 게임이 읽는 본문을 비워 두고 편집 정보만 저장하며, 게임은 오류를 고쳐 다시 저장할 때까지 그 파일을 건너뜁니다.
- 파일이 이 에디터 밖(다른 에디터 창, 텍스트 편집기, 동기화 프로그램)에서 바뀌었으면 덮어쓰기 전에 묻습니다.
- **내보내기 → XML(Ctrl+E)** 은 오류가 없을 때 XML을 따로 저장합니다.
- **내보내기 → 모드 폴더(Ctrl+Shift+E)** 는 `<모드 이름>\SKSE\Plugins\AnimationInjector\<모드 이름>\<모드 이름>.xml`과 쓰는 HKX를 출력합니다. 검색 폴더를 지정해 자산을 검사하고, 다른 모드가 주는 HKX는 외부 공급으로 표시합니다. 같은 이름의 폴더가 있으면 덮어쓰지 않습니다.
- 이전 형식(version 1~3) XML과 콤보가 든 템플릿은 열지 못합니다. 에디터에서 다시 만들어 저장하세요.

## 뷰어

**창 → 뷰포트**에서 고른 HKX를 재생합니다. 배포판에는 미리보기용 사람·크리처 스켈레톤과 스킨이 들어 있어 지원하는 HKX는 바로 재생됩니다. 소스에서 직접 빌드했다면 들어 있지 않으므로, 뷰포트의 **프리뷰 자산**에서 스켈레톤 HKX(예: `meshes\actors\character\character assets\skeleton.hkx`)를 지정하세요. 지정한 파일은 이 컴퓨터에서 기억하며, HKX와 같은 모드의 `actors` 폴더에 스켈레톤이 있으면 자동으로 찾습니다. 스킨 GLB가 없으면 뼈대만 표시합니다.

- 가운데 버튼 끌기: 회전 · Shift+가운데 버튼 끌기: 이동 · 휠: 확대/축소 · Ctrl+휠: 시야각

뷰어는 게임의 OAR 선택·IK·충돌·물리를 흉내 내지 않습니다. 최종 확인은 게임에서 하세요.

## 단축키

| 키 | 동작 |
|---|---|
| Ctrl+N / O / S | 새 프로젝트 / 열기 / 저장 |
| Ctrl+Shift+S | 다른 이름으로 저장 |
| Ctrl+E / Ctrl+Shift+E | XML 내보내기 / 모드 폴더 내보내기 |
| F7 | 컴파일(검사) |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 실행 |
| Ctrl+A · Delete | 모두 선택 · 삭제 |
| Home | 전체 보기 |
| Ctrl+` | XML 미리보기 |

## 언어와 자동 보관

- **언어** 메뉴에서 English·한국어·日本語·中文을 바로 바꿉니다. 사용자가 입력한 이름은 바뀌지 않습니다.
- 편집 중인 내용은 자동으로 보관합니다. 비정상 종료 뒤에는 시작 화면의 **자동 보관본 복구**로 되살립니다.
