# Animation Injector Editor · 1.0.0

[Animation Injector](https://github.com/skypia0147-dev/Animation-Injector)용 동작 모드를 만드는 Windows 프로그램입니다. HKX를 카드로 놓고 연결해 동작(혼자 하는 동작·페어)을 만들고, 게임이 읽는 XML이나 모드 폴더로 내보냅니다.

## 필요 사항

- Windows 10/11 x64, Microsoft Edge WebView2 런타임(Windows 11에는 기본으로 들어 있음)
- 게임에서 쓰려면 **Animation Injector 1.0.0 이상**과 그 필수 모드
- 함께 든 `AnimationInjectorXmlCheck.exe`를 `AnimationInjectorEditor.exe`와 같은 폴더에 두세요. 저장할 때 게임이 그 XML을 읽을 수 있는지 검사합니다. 없으면 검사 없이 저장하고 경고를 보여 줍니다.

## 처음 만들기

1. **새 프로젝트**를 만들거나 저장해 둔 XML·템플릿(`.aitemplate`)을 엽니다. 창에 끌어다 놓아도 열립니다.
2. 툴바의 **＋ HKX 재생**으로 카드를 만들고, 카드의 **파일**에서 HKX를 고릅니다. HKX는 `meshes\actors\<캐릭터·크리처 폴더>` 아래에 두고, 경로에는 영문·숫자·일반 기호만 쓰세요(한글 경로의 파일은 게임이 찾지 못합니다).
3. 카드를 오른쪽 클릭해 **시작 키 입력 추가** 또는 **시작 이벤트 추가**로 동작을 시작하는 방법을 정합니다.
4. 카드의 **+ 기능**에서 무적·경직 저항·회전·자원 소모·타격 같은 기능을 더합니다. 동작 내내 켜 두는 기능과 특정 순간에 실행하는 기능을 한 목록에서 다룹니다.
5. 다음 동작으로 이으려면 카드를 오른쪽 클릭해 **전환 키 입력 추가**나 **전환 이벤트 추가**를 고르고, 출력 핀을 다음 카드로 끌거나 **▾** 목록에서 고릅니다.
6. **F7**로 검사하고 **Ctrl+S**로 저장합니다. 오류 목록의 항목을 누르면 그 카드로 이동합니다.

## 그래프 다루기

- 입력·이벤트·조건·QTE·전환이 모두 한 캔버스에 있습니다. 카드를 더블클릭하면 그 동작의 흐름만 보여 줍니다.
- **정렬 ▾**: 전체 정렬, 고른 동작만 정렬, 요약 보기/펼친 보기.
- 빈 곳을 끌어 여러 카드를 고릅니다. Shift는 더하기, Ctrl은 넣고 빼기, Space+끌기는 화면 이동입니다.
- 카드를 고르면 그 카드에 이어진 선이 강조됩니다.
- **조건** 카드는 상황(무기·이동 방향·공중·직전 동작·날씨 등)에 따라 갈 동작을 고르고, **QTE**는 결과(성공·실패·완벽)마다 다음 동작을 정합니다.
- **이벤트 등록** 카드에는 프로젝트에서 쓰는 이벤트 이름과 그 이벤트가 할 일을 모아 둡니다.
- 키 입력은 키·패드 버튼을 직접 정하거나 게임 동작(점프, 질주, 웅크리기 …)으로 고를 수 있습니다. 게임 동작은 플레이어의 키 설정을 따라갑니다.

## 저장과 내보내기

- **저장(Ctrl+S)** 은 게임이 읽는 XML로 저장합니다. 카드 배치 같은 편집 정보도 같은 파일에 들어가므로, 다시 열면 그대로 이어서 편집할 수 있습니다.
- 다른 컴퓨터에서 열어도 XML과 같은 모드 폴더 안의 HKX와 소리 파일을 자동으로 다시 찾습니다.
- 오류가 있어도 저장할 수 있습니다. 다만 게임은 오류를 고쳐 다시 저장할 때까지 그 파일을 읽지 않습니다(이미 저장한 적이 있는 파일이면 마지막 정상 내용을 읽습니다).
- 파일이 이 에디터 밖에서 바뀌었으면 덮어쓰기 전에 묻습니다.
- **내보내기 → XML(Ctrl+E)** 은 오류가 없을 때 XML을 따로 저장합니다.
- **내보내기 → 모드 폴더(Ctrl+Shift+E)** 는 모드 관리자로 바로 설치할 수 있는 폴더를 만듭니다. XML과 쓰는 HKX·소리 파일이 들어가며, 다른 모드나 게임이 주는 파일은 따로 표시합니다. 같은 이름의 폴더가 있으면 덮어쓰지 않습니다.
- 브라우저 패널의 **소리**에는 모드 폴더의 소리 파일이 모입니다. ▶로 들어 볼 수 있고(.wav), 모드 폴더로 내보낼 때 함께 복사됩니다.

## 뷰어

**창 → 뷰포트**에서 고른 HKX를 재생합니다. 사람·크리처의 미리보기용 스켈레톤과 스킨이 들어 있어 바로 재생됩니다. 다른 스켈레톤을 쓰려면 뷰포트의 **프리뷰 자산**에서 지정하세요.

- 가운데 버튼 끌기: 회전 · Shift+가운데 버튼 끌기: 이동 · 휠: 확대/축소 · Ctrl+휠: 시야각

뷰어는 게임의 충돌·물리 등을 재현하지 않습니다. 최종 확인은 게임에서 하세요.

## 단축키

| 키 | 동작 |
|---|---|
| Ctrl+N / O / S | 새 프로젝트 / 열기 / 저장 |
| Ctrl+Shift+S | 다른 이름으로 저장 |
| Ctrl+E / Ctrl+Shift+E | XML 내보내기 / 모드 폴더 내보내기 |
| F7 | 검사 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 실행 |
| Ctrl+A · Delete | 모두 선택 · 삭제 |
| Home | 전체 보기 |
| Ctrl+` | XML 미리보기 |
